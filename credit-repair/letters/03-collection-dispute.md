# Letter 03 — Collection Dispute (to the Bureau)

**When to use:** A collection tradeline on the bureau report is inaccurate, not the client's, duplicated, unverifiable, or obsolete (past the §605 reporting period). This letter goes to the **bureau** under §611. In parallel, the client holds a separate right against the **collector**: under FDCPA §809, the collector must validate the debt on timely written request — use Letter 04 for that.
**Uso:** Para disputar una colección en el reporte del buró. La validación con el cobrador va aparte, con la Carta 04 (FDCPA §809).

**Closing checklist**
- [ ] Enclosures: copy of government photo ID; proof of address; any supporting documents (e.g., prior validation request + mailing proof)
- [ ] Exactly one dispute ground selected — the one that is factually true for this client
- [ ] If the debt is recent and actively collected: Letter 04 sent to the collector in the same round
- [ ] Sent certified mail, return receipt requested; mailing date and ~30-day deadline logged
- [ ] Copy given to the client
