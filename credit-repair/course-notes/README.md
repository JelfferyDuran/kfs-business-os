## Consolidation rules (non-negotiable)

1. **Distill, never copy.** Extract principles, frameworks, decision rules, and checklists — then rewrite them in KFS's own words as KFS SOPs. Do **not** copy course text, scripts, templates, or letters verbatim. Copyright aside, this repo is public; nothing here may reproduce the course's material.
2. **One note per class (or per coherent topic).** File name: `clase-NN-short-topic.md`.
3. **Every distilled note carries this header:**
   - **Source class title** (title only — not the class content)
   - **Date distilled**
   - **The principle** — the underlying rule, in one or two sentences
   - **How KFS applies it** — the concrete SOP step, checklist, or decision rule KFS uses
4. **Compliance filter before anything lands.** Any course tactic that conflicts with `../01-compliance-and-billing.md` (promising removals, disputing accurate items as errors, identity tricks, advance fees) is rejected or rewritten to the compliant version — and the rejection is noted in the note, so the reasoning survives.
5. **Cross-link, don't duplicate.** If a distilled principle changes how a letter or SOP works, link to it from the letter/SOP instead of pasting the text in two places.
